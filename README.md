# Pepe The Ponderland Warrior

Pepe The Ponderland Warrior is a 2D action-platformer game developed with Unity for Android. The game implements the Fuzzy Sugeno algorithm to create dynamic enemy behavior and decision-making during gameplay.

## Features

* 2D Action Platformer Gameplay
* Multiple Stages and Challenges
* Enemy AI using Fuzzy Sugeno Algorithm
* Android Platform Support
* Character Combat System
* Interactive Game Environment

## Technologies Used

* Unity Engine
* C#
* Android SDK
* Fuzzy Sugeno Algorithm
* UML Modeling

This repository includes:

## AI Implementation

The game utilizes the Fuzzy Sugeno algorithm to determine enemy behavior based on various gameplay conditions, creating more adaptive and engaging interactions.
